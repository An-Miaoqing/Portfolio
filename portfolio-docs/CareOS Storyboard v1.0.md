# **After this, I think we enter the final planning stage**

Up to now we’ve answered **what** the visitor sees.

The next stage is answering **how** they see it.

That means designing:

- the page grid,
- spacing,
- typography,
- motion,
- colors,
- reusable components,
- transitions,
- responsive behavior.

In other words, we’ll create the **Design System**.

And I actually think that’s where the portfolio will start to feel like a real product rather than a collection of web pages.

**This is the stage I would tackle next**, because once the design system is defined, every chapter can be built consistently and much faster by Codex.
